# 나만의 클래스 설계실

### 👉 바로 쓰기: **https://trmoo.github.io/object-oriented/**
설치 없이 브라우저에서 바로 열립니다. 수업 시간에는 이 주소를 학생들에게 알려 주면 됩니다.

---

고등학교 「정보 · 프로그래밍」 **객체 지향 프로그래밍** 단원 학습용 웹앱입니다.
학생이 자기만의 클래스를 설계하면 **파이썬 코드가 그 자리에서 만들어지고, 실행되고,
수행평가 평가요소가 자동으로 확인**됩니다.

- 대상: 고등학교 1학년 (2학기 프로그래밍)
- 성취기준: `[12정03-08]` 객체를 구현하는 클래스와 인스턴스를 활용하여 프로그램을 작성한다.

## 학생용 사용법 (3줄)
1. **1번 탭**에서 클래스 이름을 정하고, 속성과 메소드를 추가하세요. 오른쪽에 코드가 저절로 만들어집니다.
2. **2번 탭**에서 「▶ 실행」을 눌러 결과와 객체 상자를 확인하고, 코드를 직접 고쳐 보세요.
3. 다 되면 **5번 카드에서 `.py` 또는 설계 파일로 저장**하세요. (창을 닫으면 설계가 사라집니다)

## 이 앱의 특징
- **인터넷이 없어도 파이썬 코드가 실행됩니다.** 교실 조건에 맞추어 교안에 나오는 문법만
  해석하는 작은 파이썬을 앱 안에 넣었습니다. 설치도 필요 없습니다.
- **정보 은닉을 눈으로 봅니다.** `myCar.__speed` 처럼 비공개 속성을 클래스 밖에서 꺼내면
  실제 파이썬처럼 `AttributeError` 가 나고, 어떻게 고쳐야 하는지 한국어로 알려 줍니다.
- **잘못된 값을 막는 설정자**를 체크 한 번으로 만들 수 있습니다.
  나이에 음수를 넣어 보면 왜 메소드를 거쳐야 하는지 바로 알게 됩니다.
- **개인정보를 저장하지 않습니다.** 이름·학번을 묻지 않고, 브라우저에도 아무것도 남기지 않습니다.

## 교사용 안내
- **2차시(설계)**: 학생이 탭①을 채우고 **「🖨 설계지 인쇄」** 를 누르면 수행평가 설계지와 같은
  5칸 양식(+ 코드 + 평가요소 체크)이 인쇄됩니다. 그대로 걷어 도장을 찍어 주면 됩니다.
- **3차시(실전)**: 평가는 컴퓨터실 IDLE 에서 진행합니다. 이 앱은 **설계와 연습 도구**이며,
  학생이 손으로 타이핑하는 연습을 하도록 앱 안에도 안내를 넣어 두었습니다.
- 탭① 의 클래스 예시 49개는 수행평가 설계지의 목록과 같습니다.
  예시를 그대로 제출하면 감점이라는 안내가 앱에 함께 표시됩니다.
- 화면에 나오는 점수는 **코드 모양만 보고 매긴 예상 점수**입니다. 실제 채점은 교사가 합니다.

## 실행 방법

### 1) 웹에서 열기 (가장 간단)
**https://trmoo.github.io/object-oriented/** — 주소만 알면 됩니다.

### 2) 인터넷이 끊긴 교실에서 — 파일 하나로
`npm run build` 로 만들어지는 `dist/index.html` 은 **외부 참조가 하나도 없는 단일 파일**입니다.
더블클릭하면 서버도 인터넷도 없이 바로 열리고, USB 에 담아 옮겨도 그대로 동작합니다. (약 111KB)
위 웹 주소에서 「다른 이름으로 페이지 저장」을 해도 같은 파일을 얻을 수 있습니다.

### 3) 개발용
```bash
cd object-oriented
npm install
npm start        # http://localhost:5174
```

| 명령 | 하는 일 |
|---|---|
| `npm install` | 의존성 설치 |
| `npm start` | 개발 서버 실행 + 브라우저 열기 |
| `npm run build` | `dist/index.html` 한 파일로 빌드 |
| `npm test` | 미니 파이썬 해석기와 평가요소 검사 자체 점검 |

## 만든 것
- 미니 파이썬 해석기 (`src/pymini.js`) — 토큰화 → 구문 분석 → 실행.
  `class` · `__init__` · `self` · 접근자 · 설정자 · 조건문 · 반복문 · `random` · `math` ·
  f-string 을 지원하고, **비공개 속성의 이름 맹글링까지 실제 파이썬과 같게** 동작합니다.
- 코드 조립기 (`src/codegen.js`) — 설계 내용을 교안·수행평가 예시와 같은 모양의 코드로 만듭니다.
- 평가요소 검사기 (`src/rubric.js`) — 글자 맞추기가 아니라 문법 나무(AST)를 읽으므로
  학생이 손으로 고친 코드도 그대로 채점됩니다.

개발 기록과 원본 자료 요약은 `CLAUDE.md` 에 있습니다.
